# Skref

Dagatal, dagbók og verkefnalisti fyrir fólk sem á erfitt með að byrja. Stór verkefni eru brotin niður í lítil skref og undirverkefni, með tengingum, samhliða áföngum, áminningum, endurtekinni dagskrá og stigum.

Opnaðu appið á GitHub Pages-slóð þessarar geymslu og settu það á heimaskjáinn:

- **iPhone:** opnaðu í Safari, ýttu á Deila og veldu „Bæta á heimaskjá“.
- **Android:** opnaðu í Chrome, opnaðu valmyndina og veldu „Setja upp forrit“.

Gögnin vistast aðeins í tækinu sjálfu og fara aldrei á GitHub. Taktu afrit af og til undir Stillingar > Sækja afrit.

Ef `index.html` er uppfært þarf að hækka útgáfunúmerið (`skref-v3`) í `sw.js` svo símar sæki nýju útgáfuna.
